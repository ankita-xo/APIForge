# APIForge

APIForge is a developer-focused API testing and debugging platform inspired by tools such as Postman.

The long-term goal is to combine API testing, AI-assisted debugging, automated test generation, and microservice observability into a single developer-friendly platform.

## Project Status

🚧 Under Development

## Planned Features

- API request builder
- HTTP request execution
- Collections
- Environments and variables
- Request history
- Automated API testing
- AI-assisted test generation
- AI-powered response analysis
- API documentation generation
- Microservice tracing
- OpenTelemetry integration
